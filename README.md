# SDOS 2026 – Luka Jovetić

Laboratorijske vježbe i projekat iz predmeta **Sistemi za digitalnu obradu signala**
(Elektrotehnički fakultet Banja Luka, 2026).

Platforma: ADSP-21489 EZ-KIT (SHARC), CrossCore Embedded Studio.

| folder | sadržaj |
|---|---|
| `lab5_eq` | Lab 5, tema 6: stereo ekvilajzer – 5 verzija (C -O0, C -O, `biquad()`, SIMD, SIMD + dm/pm), mjerenje ciklusa i maksimalnog broja opsega u realnom vremenu |
| `projekat` | projekat iz predmeta |

## Grane

- `dev` – tekući rad; svaki zadatak se radi na posebnoj grani (`lab5/...`) i spaja u `dev` preko pull requesta
- `main` – predate verzije
